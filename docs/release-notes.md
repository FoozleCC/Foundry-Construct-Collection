# Release Notes

## v0.3.0.0 (release candidate)

- Physics Body adds per-axis world-position locks and runtime rotation actions.
- Physics Body adds action-based distance, revolute, limited revolute, and prismatic joints without introducing another behavior.
- Physics Character adds world-space movement-vector actions for full-vector or per-axis control.
- Joint constraints survive body rebuilds caused by runtime lock or collider changes.

## v0.1.0.0

- Initial public docs and release pipeline baseline.
- Camera, Camera Target, Physics, Physics Body, and Physics Character docs published.
- Physics Vehicle docs remain internal until release-ready.
